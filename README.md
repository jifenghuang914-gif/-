# Codex Skills 工作提效仓库

这个仓库用于存放个人沉淀的 Codex Skills，把日常运营分析、策略复盘、机器学习测算等工作流程固化成可复用的 AI 工作方法。后续在 Codex 中调用对应 skill，可以让 AI 直接按照既定业务口径、字段规则和输出格式执行，减少重复沟通和手工整理。

## 已收录 Skill

### `uk-redpacket-ml-strategy`

UK 红包策略机器学习式测算技能，用于根据历史红包领取、核销和策略表数据，预测新红包方案的核销率、订单量、补贴、GMV、CM3 和 REV，并输出新旧策略对比测算表。

适用场景包括：

- UK 新生命周期红包策略调整测算
- 天降红包、任务中心、犹豫时机等红包工具的新旧方案对比
- 按红包权益组合预测新券表现
- 用历史 75 天权益组合命中率估算新策略核销率
- 生成带公式、可校验的新旧策略测算表

核心方法：

1. 将红包权益文本拆解成结构化字段，例如面额、门槛、补贴力度、会员属性、来源、生命周期、频次和客单标签。
2. 优先用历史中直接命中的新权益组合计算核销率和单均表现。
3. 如果新权益未命中，则参考旧权益或相近权益，并按补贴力度变化进行小幅修正。
4. 用领取数、预估核销率和单均指标推算订单量、补贴、GMV、CM3、REV 等结果。
5. 区分周总和日均口径，保留可追溯公式，并在输出前做公式错误和关键口径 QA。

## 目录结构

```text
uk-redpacket-ml-strategy/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── calculation-caliber.md
```

其中 `SKILL.md` 是主说明文件，`references/calculation-caliber.md` 记录详细计算口径，包括 75 天历史命中、未命中回退、无门槛 cap、C补rate 分母、周总/日均、老策略 ID 锁定等规则。

## 使用方式

在 Codex 中调用：

```text
$uk-redpacket-ml-strategy
```

然后提供策略表、红包领取表、红包核销表、核心指标表等数据目录，说明日期窗口和输出口径。AI 会按照 skill 中沉淀的规则完成数据解析、预测测算、Excel 输出和校验。

## 维护原则

- 新增 skill 时保持标准结构：`SKILL.md`、可选 `agents/`、`references/`、`scripts/`、`assets/`。
- 复杂计算口径放入 `references/`，避免主 skill 过长。
- 只沉淀真正影响工作结果的业务规则，不堆泛泛说明。
- 每次更新后尽量记录关键适用场景和输出口径，方便后续复用。
